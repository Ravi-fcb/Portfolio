## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Python 3 or another local static web server
- Internet connection for loading Three.js from a CDN, if applicable

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ravi-fcb/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open the website in your browser:

   ```text
   http://localhost:8000
   ```

Alternatively, open `index.html` directly in your browser, although running a local server is recommended.
